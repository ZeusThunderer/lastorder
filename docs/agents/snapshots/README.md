# Снапшоты ответов узла

`uv run python tools/snapshot_replies.py --preset lab|misaka --out docs/agents/snapshots/<дата>-<пресет>.md`
(env `LLM_NODE_MODEL`, уровень `node` по ADR-023). Промпты — из сборки шага T-011
(`build_step_prompt`, порядок и бюджеты блоков KNOWLEDGE v2 §9): 3 запроса из task1 ч.2 §2
(не шаг — JSON-контракт в user явно отключён) + 2 полных шага по наблюдению
`dev/bench_cases/node_step.json` — `plain` и `masked`. Ответ шага проходит `parse_step_reply`.
Проверки: русский, без эмодзи, 1–3 предложения, завещание 2–4 строки, нет сырых id, числа
черт не называются, `option_id` из списка. Качество — глазами.

## 2026-10-17, openrouter/qwen/qwen3.7-flash (уровень node), сборка шага T-011
- `lab` (5/5 OK, $0.0001): шаги `plain` и `masked` дают валидный `StepReply`, `option_id` из
  списка, `new_term`/`msg` по формату GOALS_COMMS; правило знаний в `masked` держится —
  модель оперирует термином, не именем игры.
- `misaka` (4 OK, 1 FAIL, $0.0002): завещание в одну строку — та же слабость пресета, что в
  E0 (2026-10-14). Шаги OK; реплики в третьем лице по канону пресета.
- Вывод: JSON-контракт шага модель держит в обоих режимах; для завещаний (рефлексия смерти,
  T-013) проверка «2–4 строки» остаётся в коде, повтор при нарушении.

## 2026-10-14, openrouter/xiaomi/mimo-v2.6-flash
- `lab`: все проверки OK. Огрехи: «я называл», «я копал» — родовые окончания вопреки стилю;
  завещание нумерованным списком.
- `misaka`: завещание в одну строку (FAIL). Реплика на совет из чата **нарушает правило знаний**:
  «ищу блоки с синими прожилками» — знание об алмазах извне. Модель приняла совет как команду
  («Иду измерять») при доверии 5.
- Вывод для E2: в шаге игры ответ — JSON с отдельными полями (`say`, `will`), а не свободный текст;
  проверка завещания по строкам в коде, повтор при нарушении; правило знаний усилить примерами
  в промпте только после повторного прогона на локальной модели.
