(900 с) → `will.emergency`. Жизни 166–178 (13 шт.) закрыты аварийными завещаниями, цикл по TTL
45 мин — узел честно пережил ночь без нормальной воли [проверено: `docker logs
lastorder-node-1-1`, grep `will.emergency` за 2026-11-08].

без перезапуска (аптайм хаба 2 дня). Причина 409 и причина самоосвобождения не установлены
[предположение: осевшее состояние сессий после убийств по квоте; перезапуск хаба не понадобился].
