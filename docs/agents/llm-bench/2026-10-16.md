## Методика

- Системный промпт — настоящий шаблон персонажа через `PersonaProvider` (пресет `lab`, узел 00007,
  неизменён); case-файлы добавляют только инструкцию задачи и пользовательский ввод.
- Случаи `node`: шаг (наблюдение в `plain` → JSON StepReply по предварительной схеме NETWORK.md §5;
  уточнит T-011) и 3 запроса task1 через `tools/snapshot_replies.py` (стилевые проверки оттуда же).
- Случаи `smart`: рефлексия (события → core memory ≤1.5 КБ + ≤3 кандидата по KNOWLEDGE.md §2),
  завещание (2–4 строки, урок + шутка), цели сети (сводка базы → 1–3 цели, JSON).
- `repeat 2` на модель на случай. `REASONING_OFF=1` для всех (клиент шлёт отключение; модели с
  обязательным reasoning его игнорируют — см. ниже). Потолок выходных токенов: 1500 (node) и
  2000 (smart); для GPT-5 Nano и GLM-5.3 (обязательный reasoning) сделаны перепрогоны @4000.
- Бюджет-стоп: `--max-usd`, при превышении прогон останавливается (не срабатывал: самый дорогой
  прогон $0.0073 при потолке $0.2–0.5).
- «$/3 узла/ч» — пересчёт по реестру вызовов ADR-022 (NETWORK.md §6: шаг ≤1350/ч, болтовня 30/ч,
  рефлексия 33/ч, завещание 9/ч, цели 4/ч) с **измеренными** токенами случаев; для болтовни —
  номинал 1200/150. Это вклад уровня; весь бюджет сети ≤ $0.25/ч.
- Стоимость на вызов — отчёт провайдера через litellm (`response_cost`); если его нет — оценка по
  таблице цен выше. Задержка — стеночное время вызова целиком.
- Метрики стиля: emoji, >3 предложений в шаге, число черт в речи (эвристика по названиям черт),
  доля кириллицы; для task1 — проверки snapshot_replies.

## Качественные наблюдения (по сырым ответам ниже)

- **Qwen3.7 Flash**: компактные ответы в характере, живые термины («полосатый маяк»), лучший
  шаг-JSON: короткие `why`/`say`, осмысленные `note`/`msg`. Одно нарушение: завещание одной
  строкой (#0) — при том что #1 образцовое, 4 строки.
- **GPT-5 Nano**: обязательный reasoning → шаг либо пустой (1500), либо 16 с и $1.14/ч (4000);
  речь канцелярская («Зафиксировано», «Протокол»), местами докладывает несделанное («Скрафтил
  верстак» — выбран вариант, не сделан). Для шага не годится.
- **Gemini 2.5 Flash Lite**: самый быстрый (p50 1 с), но многословие (5–6 предложений в свободных
  ответах), выдумывает свои префиксы хэндлов («obj:»), а главное — эндпоинт истекает 2026-10-20.
- **Mistral Small 3.2**: стабильно нарушает стиль (12 предложений, завещание 9 строк), коверкает
  хэндлы кириллицей («об:28af», «чёт:2254»), в одном ответе вывела число черты («любознательность 5»).
- **MiMo v2.6** (база E0): в характере, но p50 10 с / p95 18 с — у самой границы каденции шага;
  $0.30/ч.
- **DeepSeek V4.1 Flash**: лучшие по плотности рефлексии: точные кандидаты с evidence_event_ids,
  чистые цели сети; завещание — одна строка (урок+шутка в абзаце). Reasoning отключается, отсюда
  212 вых. токенов и $0.015/ч.
- **DeepSeek V3.2**: то же качество, вдвое дороже и втрое медленнее — нет преимуществ.
- **GLM-5.3 Flash**: самый глубокий и самый «литературный» (кириллица 0.98, чистые завещания
  урок+шутка), но обязательный reasoning: требует MAX_TOKENS ≥ 4000, p95 16 с и ×6 к цене вызова.
- **Qwen3.8 Flash**: дёшев и быстр, но речь калькирует («синтезировать кровать») и кириллица 0.88.

## Рекомендация

Выбор за надзором и пользователем. По замеру:

- **node: `openrouter/qwen/qwen3.7-flash`** — единственная модель уровня, укладывающаяся в бюджет
  с запасом ($0.071/ч) при каденции шага (p50 2.6 с), чистом JSON и лучшем стиле. Запасной вариант:
  Mistral Small 3.2 ($0.21/ч), если понадобится запас прочности по длине контекста, ценой стиля.
- **smart: `openrouter/deepseek/deepseek-v4.1-flash`** — 4/4 схемы, p50 2.3 с, $0.015/ч; глубина
  рефлексии и цели сети по сырым ответам не хуже альтернатив. Если рефлексия покажется мелкой —
  `z-ai/glm-5.3-flash` (глубже и литературнее, но обязательный reasoning: `LLM_SMART_MAX_TOKENS≥4000`,
  p95 16 с, $0.096/ч — всё ещё в бюджете: 0.071 + 0.096 = $0.17/ч ≤ $0.25).

Отклонены: GPT-5 Nano (обязательный reasoning: шаг 16 с, $1.14/ч — превышение бюджета в 4.5 раза);
Gemini 2.5 Flash Lite (истекает 2026-10-20, многословие); MiMo v2.6 (p50 10 с при каденции 8–15 с,
$0.30/ч); DeepSeek V3.2 (дороже и медленнее V4.1 Flash без выигрыша); Qwen3.8 Flash (калькированная
речь, хотя и самая дешёвая).

Замечание для рантайма (уже в клиенте): при ошибке «Reasoning is mandatory» клиент повторяет вызов
без флага отключения — обязательный reasoning перестаёт ронять вызов, но оплата токенов рассуждения
остаётся на модели.
