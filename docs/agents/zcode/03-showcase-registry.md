# 03. Показ 13.11 — «Реестр: судьба по номеру»

Замысел — Last Order, `docs/progress/lastorder/plan-12-13.md`, раздел 13.11. Зритель называет
номер сестры (или «случайный») → видит запись реестра смертей: линия тела, причина, свидетель;
счётчики сети (всего / с названной причиной / безымянных). Затем выбирает правило из базы
(«ночь — прятаться в камне», «у воды стоп») → живая смена следует ему или платит за
нарушение. Зритель может предложить своё правило — сеть примет его или опровергнет.

Реестр — инструмент Last Order в её мастерской (`workshop/`), не код проекта (ADR-041).
Код под показ не пишем; проверяем путь и чиним среду, если она мешает.
