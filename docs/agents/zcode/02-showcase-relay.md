# 02. Показ 12.11 — «Эстафета знаний»

Замысел — Last Order, `docs/progress/lastorder/plan-12-13.md`, раздел 12.11. Коротко: зритель
задаёт короткий вопрос о мире → Last Order передаёт его живой сестре задачей → сестра
отвечает в игровом чате, опираясь на базу → к концу смены предлагает знание → Last Order
решает, и ответ становится записью базы с номером. Умерла до ответа — зритель видит смерть,
реестр и завещание.

Код под показ НЕ пишем (ADR-032, ADR-041): всё это — обычные механизмы сети. Твоя работа —
проверить путь заранее, убрать то, что ломает его, и дать оператору шпаргалку.

## Шпаргалка оператору — показ «Эстафета знаний»
1. Подать вопрос: на странице доски (или через меня) задача `to: last-order`, текст вида
   «Вопрос зрителя: <вопрос>. Передай сестре, ответ пусть прозвучит в чате». Пример — #148.
2. Смотреть ответ: игровой чат на камере слота 2 (запись в media) и строка `chat.line` в
   `docker logs lastorder-mind-N-1`; решение по знанию — на доске и в базе (летопись
   Last Order). Цикл ≈ 3–4 мин.
3. Сестра умерла до ответа — это часть показа: смерть в реестре, завещание в базе, в том же
   слоте рождается следующая (цикл ~75 с, проверено утром). Вопрос можно повторить новой
   задаче — Last Order передаст её следующей сестре.
4. «Тишина» сети на время показа: задача `to: last-order` «другие задачи не брать N минут» —
   она решает сама; срочный стоп — сказать ей в консоли HAPI.
5. Если тело слота упало (экран замер, чат молчит): ничего не делать ~2 мин — разум сам
   просит перезапуск тела (проверяю сегодня, 01.B); тревога придёт на доску.
