# 02. Показ 12.11 — «Эстафета знаний»

Замысел — Last Order, `docs/progress/lastorder/plan-12-13.md`, раздел 12.11. Коротко: зритель
задаёт короткий вопрос о мире → Last Order передаёт его живой сестре задачей → сестра
отвечает в игровом чате, опираясь на базу → к концу смены предлагает знание → Last Order
решает, и ответ становится записью базы с номером. Умерла до ответа — зритель видит смерть,
реестр и завещание.

Код под показ НЕ пишем (ADR-032, ADR-041): всё это — обычные механизмы сети. Твоя работа —
проверить путь заранее, убрать то, что ломает его, и дать оператору шпаргалку.

## Путь, который проверить (репетиция до показа)
- [ ] Оператор → Last Order: задача на доске (`kind: task`, `to: last-order`) с вопросом
  зрителя. Права есть: `runtime/hive/board.py` `_POST_RIGHTS`.
- [ ] Last Order → сестра: задача `to: node` живой сестре (права есть). Проверить, что
  Last Order выбирает живую сестру, а не умершую (номер из `/runner/status` слота).
- [ ] Сестра отвечает в игровом чате (рычаг чата) — видно в логе `mind-N` и на камере
  слота 2. Если сестра отвечает только на доске — это инструкция сестры
  (`agent/<шаблон сестры>/AGENTS.md`, разделы о задачах оператора и о чате), не код.
- [ ] Предложение знания → решение Last Order (`agent/network/skills/decide/SKILL.md`) →
  запись `k-NNNN` в базе (`knowledge/` под git в hive). Засечь, сколько это занимает.
- [ ] Засечь весь цикл «вопрос → ответ в чате». Если дольше ~5 мин — посмотреть, где ждут
  (пробуждения `wait_events`, интервал доски), и сказать оператору; ускорять кодом — только
  если узкое место в среде, а не в поведении.

## Что видит зритель
- [ ] Камера слота 2 (`BODY_CAMERA_2=1`): запись в `media`, вырезка — через Last Order
  (`agent/network/reference/` справка по видео). Прямого порта на хост у `media` нет
  (T-063). Если оператору нужен живой поток в OBS/VLC — это решение оператора: вопрос ниже.
- [ ] Страница доски — задачи, ответ, решение по предложению.
- [ ] Консоль HAPI — оператор говорит с Last Order, она отвечает в чате консоли.

## Шпаргалка оператору (написать в конце этого файла)
