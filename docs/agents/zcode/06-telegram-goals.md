# 06. Telegram и цели оператора («работа на один день»)

Решение уже принято (ADR-030, ADR-041): Telegram-канал сети **строит Last Order сама** в своей
мастерской (`workshop/`) и публикует; код проекта бота НЕ пишет. Среда для этого есть:
- гранты (T-046): Last Order просит `request_grant(kind="egress", what="api.telegram.org")` и
  `request_grant(kind="secret", what="telegram_token")`; оператор одобряет на странице доски,
  значение секрета вводит там же, к ней оно не возвращается (`runtime/hive/mcp.py`
  `grant_request`, `runtime/hive/grants.py`);
- выход наружу — через прокси `egress`, белый список берётся из hive в реальном времени
  (`docker/egress/proxy.py`);
- цели оператора — строки в `GOALS.md` рабочего места Last Order (`agent/network/GOALS.md` —
  шаблон и инструкция внутри файла); изменение будит её само.

Твоя роль — подготовить путь, помочь оператору с ручными шагами и проверить, что среда не
мешает. Если Last Order упирается в среду (нет пакета, нет прав на файл, прокси режет) —
чинишь среду. Если в поведение — правишь инструкцию/навык, не пишешь бота за неё.

## Шаги оператора (дать ему этим списком)
- [ ] BotFather → новый бот, токен.
- [ ] Канал (или группа) сети, бот — админ канала; id или @имя канала.
- [ ] Строка в `GOALS.md` Last Order, например: «канал сети в Telegram: летопись, завещания,
  реестр смертей — для зрителей курса». Команда добавления — в комментарии `GOALS.md`.
- [ ] Одобрить два гранта Last Order на доске; ввести токен в поле секрета.

## Шаги проверки (твои)
- [ ] До всего: из `last-order` через прокси `egress` доступа к `api.telegram.org` нет
  (белый список пуст) — записать как исходное состояние.
- [ ] После гранта egress: доступ есть только к этому домену; другие домены по-прежнему
  закрыты.
- [ ] Секрет: Last Order получает токен тем способом, который описан для секретов
  (`grants.py`), и он не попадает в её журналы, доску и летопись (поиск по логам).
- [ ] Её инструмент в `workshop/` шлёт первое сообщение в канал. Засечь, сколько заняло от
  строки в `GOALS.md` до первого поста.
- [ ] Если она публикует инструмент сёстрам — сёстрам токен не уходит (у них нет гранта).

## Вопросы оператору
- Канал публичный (для зрителей курса) или закрытый? От этого зависит, что она туда пишет —
  это строка цели, не код.
