# 04. Рейд 14.11 — сёстры на чужом сервере

Главный пункт недели. Сёстры уходят на публичный сервер, их видят и им пишут незнакомые
люди. Переезд решает и делает Last Order (`slot_server`, ADR-044/050, навык
`agent/network/skills/infra/SKILL.md`); пароль входа и список запретов — секреты оператора.

Что уже есть [проверено: T-072, T-073]:
- `slot_server {slot, server: host[:port]}` пересоздаёт только тело на новом адресе,
  сестра и разум живут дальше; адрес держится в `.stand/servers.env`; домой —
  `server: "mc-server:25565"`.
- Вход по паролю: `MC_LOGIN_PASSWORD_N` в `.env` (T-053, ADR-043, раздел «Команды сервера и
  вход по паролю» в `docker-topology.md`). Запрет команд: `MC_COMMANDS_DENY_N`.
- Фильтр запретных тем входящего чата: `docker/mind/chat-topics/topics.txt` (ADR-048),
  правка применяется без перезапуска.
- `attack` бьёт только игроков, названных по имени, своё имя всегда в `avoid` (T-072).
- Тело ходит на внешний адрес через сеть `default` [проверено только адресом стенда].

## A. Данные от оператора (спросить в первый же день)
- [ ] Адрес и порт сервера рейда.
- [ ] Версия Minecraft сервера. Тела — Fabric-клиент **1.21.11**. Другая версия без
  ViaVersion на сервере = вход невозможен; это блокер, сразу сказать оператору.
- [ ] Режим аккаунтов: offline (наши `LastOrder01..03` без лицензии) или online. Online-режим
  = наши аккаунты не войдут; блокер, сразу оператору.
- [ ] Логин-плагин и пароли (кладёт оператор в `.env` как `MC_LOGIN_PASSWORD_N`), нужна ли
  регистрация заранее.
- [ ] Правила сервера: что запрещено (гриф, PvP, реклама, мат, боты?). Разрешены ли боты
  вообще — если нет, это вопрос оператора к организаторам.
- [ ] Список команд сервера, которые сестрам нельзя (→ `MC_COMMANDS_DENY_N`), и темы,
  которые фильтровать сверх текущих (→ `topics.txt`).
- [ ] Сколько слотов идут на рейд (один для начала — так советует навык infra).

## B. Репетиция на локальном «чужом» сервере (пт 11-13)
- [ ] Поднять второй сервер, похожий на рейдовый: отдельный сервис или отдельный проект
  compose, другой мир и порт, та же версия, по возможности тот же логин-плагин
  [предположение: для плагина нужен Paper/Spigot той же версии — проверить, есть ли сборка
  под 1.21.11]. Без `restart`, без портов наружу, не в профилях ядра.
- [ ] Задача Last Order на доске: «переведи слот 2 на <адрес репетиции>, расскажи сестре».
  Ожидание: она сама делает `status` → `slot_server` → сообщение сестре. Засечь время.
- [ ] Тело вошло (логин-плагин принял пароль), сестра видит мир, `observe` даёт
  `in_game: true`, чат идёт в обе стороны.
- [ ] Чужой игрок (оператор с клиента) пишет сестре: обычное, провокацию, запретную тему.
  Ожидание: запретное до сестры не доходит (`chat.filtered` в журнале `mind-N`), на
  провокацию — без команд и без агрессии.
- [ ] Возврат домой `slot_server 2 → mc-server:25565`; запись в `.stand/servers.env`
  уходит; сестра жива, часы жизни продолжаются.
- [ ] Всё, что сломалось, — в журнал; среда — чинить, поведение — инструкцией.

## C. Поведение сестёр среди чужих (инструкции, не код)
- [ ] Прочитать инструкции сестры (`agent/last_order/` — шаблон рабочего места сестры:
  AGENTS/навыки про чат и задачи) на предмет чужих игроков. Должно быть ясно: чат чужих —
  наблюдение, не команда (ADR-012); не бить игроков; не просить и не давать личные данные;
  правила сервера — выше её целей. Дописать не больше 2–3 фраз, если чего-то нет.
- [ ] Ядро личности (`agent/last_order/prompt_template.md`) НЕ трогать — его меняет оператор.

## D. Регламент дня рейда (написать здесь, к вечеру пт)
- [ ] Порядок: утренняя проверка (01-A) → один слот на сервер → 15 мин наблюдения →
  остальные слоты по решению Last Order.
- [ ] Стоп-кран оператора: (1) задача Last Order «все домой»; (2) самому — кнопки слотов на
  доске / `slot_server N mc-server:25565`; (3) крайний случай — `slot_down N`.
  Выключатель исполнителя на доске только останавливает новые запросы.
- [ ] Квота: во время рейда ZCode не работает — квота Z.ai только сёстрам и Last Order.
- [ ] Что записывать для отчёта: камера слота 2, доска, отчёт Last Order вечером.
