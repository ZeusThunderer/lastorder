## C. Хвосты
- [x] **Снятие `stuck`-тревог (найдено 12.11 в утренней проверке).** Раннер поднимает
  `stuck` на каждый тихий период сессии и не снимает при возобновлении оборотов; на доске
  копятся однообразные открытые тревоги, их видит публика. Сделать: раннер помнит id своей
  тревоги и переводит её в закрытое состояние, когда сессия снова делает обороты; права
  перехода в `board.py` — автору тревоги. Тест в `tests/test_hive_board.py`.
  [сделано: коммит 68d68bf — статус `cleared` с правом автора (`open → cleared`),
  эндпоинт `POST /board/alarms/{id}/clear`, бейдж на странице; раннер помнит id и снимает
  при возобновлении оборотов; тесты board+runner. Hive задеплоен (up.sh), правка раннера
  вступает после пересоздания node-N — после показа. Старую кучу тревог ack-ает оператор]
- [x] **`mc_restart` и мир по требованию.** Сейчас `mc_restart` при остановленном мире
  поднимает `mc-server`, и он работает без тел (уборка мира запускается только после
  остановки тела). Сделать так, чтобы после `mc_restart` шла та же уборка, или чтобы без тел
  мир не поднимался — выбери одно, тест в `tests/test_hive_infra.py`.
  [сделано: коммит ad3a058 — после `restart mc-server` идёт та же world_gc («без тел мир
  гасится»); тест test_mc_restart_ends_with_the_world_gc. Исполнитель исполняет
  dev/infra_bridge.py из bind-mount — контейнер infra перезапущен, правка живая
  [проверено: healthy 03:59]]
- [x] **Шум py4j при загрузке тела.** Пока тело грузится, `mind-N` пишет десятки трейсбеков
  `Py4JNetworkError` в секунду. Поднять уровень логгера `py4j` до WARNING в разуме и
  писать одну свою строку на попытку переподключения (с номером и паузой). Логика повторов
  не меняется. [сделано: коммит c658f24 — `py4j` → WARNING в main() разума, одна строка
  `bridge reconnect attempt N in Xs` на попытку в `_call`; тесты зелёные. Деплой — вместе
  с послепоказочным пересозданием mind/node]
- [x] **`dev/slot_restart.sh`** написан для старой схемы (разум в сетевом пространстве тела).
  Либо переписать на новый порядок (`up.sh --force-recreate --no-deps body-N`, разум не
  трогать), либо пометить устаревшим и вызывать исполнитель. Обновить абзац в
  `docker-topology.md` «Перезапуск слота (T-055)».
  [сделано: коммит 3ef5103 — скрипт громко отказывает и указывает на инфра-глаголы доски;
