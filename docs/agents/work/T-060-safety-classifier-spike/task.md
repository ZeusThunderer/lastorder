# T-060. Спайк — локальный классификатор на GPU оператора как второе мнение о действиях Last Order

## Цель
Выяснить, годится ли маленькая локальная модель на RTX 2070 оператора как второе мнение о запросах
`infra` Last Order: «безопасно / рискованно / опасно» с причиной, за доли секунды, без расхода
LLM. Заодно — пригодна ли та же модель для других быстрых решений сети позже.

## Контекст
- ADR-044: безопасность действия Last Order оценивает сама; классификатор — второе мнение.
- Кандидаты, названы оператором [проверено: страницы моделей, 2026-10-31]:
  - `fastino/GLiNER2.5-multi-Decide` — 287M, mDeBERTa-v3-base, многоязычная, метки задаются при
    вызове, CPU или GPU; `pip install "gliner2[local]"`, `classify_text`.
    https://huggingface.co/fastino/GLiNER2.5-multi-Decide
  - `convaiinnovations/laya` — ~400M, ModernBERT-large, только английский; есть
    `laya-multilingual` (322M). https://huggingface.co/convaiinnovations/laya
- Запросы `infra` пишутся по-английски (инструкции Last Order — английские).
- Решение надзора: модель встраивается, только если спайк покажет пользу; встраивание — отдельная
  задача. Новый вид расхода LLM не появляется: модель локальная.

## Вопросы оператору (до `ready`)
1. GPU в Docker на хосте (Docker Desktop + WSL2 + драйвер NVIDIA) уже работает, или спайк идёт на
   хосте без Docker? Установку драйвера и CUDA оператор делает сам по инструкции.
2. Где модель живёт на стенде: отдельный сервис рядом с `hive` или процесс исполнителя T-057 на хосте?
