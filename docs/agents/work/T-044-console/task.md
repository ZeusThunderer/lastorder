# T-044. Консоль оператора на стенде — Last Order, сёстры и сеть на одной странице

## Цель
Оператор открывает одну страницу в браузере и видит всех агентов стенда: Last Order, живые
сёстры, канал «сеть», мёртвые — только чтение. Пишет любому голосом или мыслью и видит ответы и
ход работы агента вживую.

## Контекст
- ADR-041; выбор консоли — `docs/agents/console-choice.md` (T-041). **Задача в `draft`, пока
  надзор и оператор не утвердили выбор; тогда — «Объём» и критерии под выбранное решение.**
- Канал оператора, режимы и лента — T-042; долгая сессия Last Order — T-043.
- Сёстры переезжают на Pi в T-045; до того на странице — Last Order и тестовый агент Pi в слоте
  (или живой Hermes-слот только чтением, если консоль это умеет).

## Объём
Можно трогать:
- `docker/compose.yml` — сервис консоли (порт только на `127.0.0.1`, пароль), сети — только
  внутренние до hive и агентов
- `docker/console/` — образ или конфиг выбранного решения (версия пинится)
- `dev/stand_keys.py` — пароль консоли
- `docs/agents/docker-topology.md` — раздел «Консоль»
- файлы задачи

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`
- `runtime/node/` (T-045), `runtime/hive/` кроме того, что нужно консоли для чтения ленты T-042

## Критерии приёмки
- [ ] `bash docker/node/up.sh … console` поднимает консоль; страница на `127.0.0.1` закрыта
  паролем; извне хоста не открывается — проверка в отчёте.
- [ ] На одной странице: Last Order и минимум один агент слота; переключение без перезагрузки.
- [ ] Голос и мысль из консоли доходят до Last Order; ответ виден в консоли — вывод в отчёте.
- [ ] Канал «сеть»: сообщение уходит всем живым агентам; сообщения агентов оператору и тревоги
  среды видны.
- [ ] Мёртвые сессии видны только чтением.
- [ ] Рецепт оператора в `docs/agents/docker-topology.md`: одна команда подъёма, URL, где пароль.

## Проверки
```
bash dev/check.sh
```

## Ограничения
- Готовое решение не форкается и не правится; настройка — конфигом или плагином самого решения.
- ADR-033: консоль не даёт песочницам новых выходов наружу; ключей провайдеров в ней нет.
- Пути bind-mount разрешает демон, а не шелл.
