# T-054. Старт слота — нет смерти от устаревшего hp, wait_events не дольше таймаута харнесса

## Цель
Два дефекта прогона T-052. Тело, которое несколько дней простояло мёртвым, при старте слота
поднимается без ложной смерти и без лишней сессии завещания. Вызов `wait_events` не превышает
таймаут инструмента харнесса, и харнесс не считает его ошибкой.

## Контекст
- Устаревшее hp: тело восстанавливается с hp=0 → смерть через ~10 с после рождения → сессия
  завещания ~90 с на каждом старте слота. Три случая: узлы 108, 111, 112/113
  [источник: отчёт T-052, «Для lo-plan»]. Проверка смерти — `runtime/mind/executor.py:465-490`.
  Ловушка CLAUDE.md: авторесп без задачи не срабатывает, `mind-N` сам вызывает `respawnPlayer()`.
- `wait_events`: предел `WAIT_TIMEOUT_MAX_S = 600` — `runtime/mind/mcp_body.py:51`, проверка —
  `:390-399`, умолчание 30 с — `:459`. В zcode инструмент убивается через 30 с: 7 убитых вызовов
  на node-2 [источник: отчёт T-052].

## Объём
Можно трогать:
- `runtime/mind/executor.py`, `runtime/mind/mcp_body.py`;
- `runtime/node/adapters.py`, `docker/compose.yml` — предел ожидания на харнесс через окружение;
- `tests/` — новые тесты.

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`, `.env*`
- инструкции сестры (предел держит инструмент, не правило в тексте)

## Критерии приёмки
- [ ] Тест с фейковым телом: первые состояния после старта `mind-N` дают hp=0 → `mind-N` вызывает
  respawn, события `game.death` нет, завещание не запрашивается, в логе — отдельная запись
  (например `body.stale_dead`). После первого живого состояния hp=0 — обычная смерть, как раньше
  (существующие тесты пути смерти зелёные).
- [ ] Предел `wait_events` задаётся окружением (например `WAIT_EVENTS_MAX_S`); для zcode в compose —
  с запасом ниже 30 с. Вызов сверх предела не ошибка: ожидание урезается, ответ сообщает
  применённое значение. Тест на урезание и на ответ.
- [ ] Описание инструмента `wait_events` называет предел.
- [ ] `bash dev/check.sh` зелёный.

## Проверки
```
bash dev/check.sh
uv run pytest tests -k "death or wait_events"
```

## Ограничения
- Путь смерти — критичная зона: смерти без завещания не бывает. Исключение только для тела,
  которое мертво до первого живого состояния этой жизни; это не смерть узла.
- Прогон на стенде — в T-058.
