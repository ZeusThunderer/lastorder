# T-015. FastJevDecider в тактике C1

## Цель
C1 выбирает вариант через локальный FastJev на 2070 (порт `Decider`), `RuleDecider` остаётся
запасным путём по таймауту. Быстрый контур отделён от медленного LLM-шага (R6).

## Контекст
- После T-005 (спайк, цифры) и T-014 (C1 на правилах). ADR-004, ADR-023; ARCHITECTURE §3 (C1:
  таймаут 250 мс → `RuleDecider`, низкая уверенность 3 раза → запрос к C2).

## Объём
Можно трогать:
- `runtime/tactics/jev_decider.py` (новый), `runtime/tactics/` — подключение
- `docker/compose.yml` — сервис `jev` из профиля в основной состав по флагу
- `tests/test_jev_decider.py`
- файлы задачи

## Критерии приёмки (предварительно)
- [ ] Таймаут или ошибка Jev → `RuleDecider`, событие в лог. Тест с подставным сервером.
- [ ] Уверенность ниже τ три раза подряд → внеочередной шаг C2. Тест.
- [ ] Прогон на стенде: p95 решения C1 в логе, доля откатов на правила.
