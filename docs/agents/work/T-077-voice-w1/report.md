### Сделано
- `runtime/voice/speaker.py` (e10e5e7): строка `say` режется на предложения (короткие склеиваются со
  следующим, длинные — по запятой, ≤ 180 знаков); первое звучит, пока синтезируется следующее; строка в
  чат — одна, целиком, с началом звука. Новая строка заменяет ждущие (не начатые), реплика другого
  игрока в чате или голосом снимает ждущие (`Executor.on_heard`); снятые уходят в чат текстом, журнал
  `silent: replaced… / <ник> spoke`. В журнале у первой части строки `wait_s` — от `say` до первого звука (W2).
- Голос: эталон — японский оригинал (решение оператора), `.stand/voice/ref.wav` 0–11.04 с из
  Railgun S 05 2:33, `ref.txt` — японская расшифровка (Whisper, проверена по смыслу; дальше 11 с
  Whisper путает имена — не взято). Прежний эталон — `ref-designed.*`.

### Замеры [проверено, стенд, 5070 Ti]
- Сестра 00351 говорила с оператором в игре: оператор слышит голос, ударения верные; задержка «ужасная».
  Журнал: первая часть 71 знак — первый звук через 8.6 с; части 173 и 234 знака — таймаут 25 с.
- Скорость синтеза, одна и та же фраза, японский эталон:

| Движок | Синтез / длина звука | Первый звук |
|---|---|---|
| Qwen3-TTS 1.7B, transformers | ×2.5–2.6 | ~10 с |
| Qwen3-TTS 0.6B, transformers | ×2.5–2.6 (первый вызов ×6) | ~10 с |
| Fish Audio s2.1-pro, OpenRouter | ×0.5–0.8, $0.0014 за строку | ~3 с |

- Загрузка GPU при синтезе — 14 %: упор в Python-цикл по токенам, не в GPU.
- Оператор по записям `.stand/voice/bench/`: у Fish сильный акцент; оба Qwen хороши, 0.6B чуть лучше.
