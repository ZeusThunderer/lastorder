# T-017. Общение узлов — Мисака-нет, игровой чат, болтовня с режиссёром

## Цель
Узлы общаются по ADR-022:
- координация идёт попутно в шаге (0 вызовов) через Мисака-нет и игровой чат с лимитами;
- болтовня — отдельные короткие вызовы `node` в лимите `CHATTER_CALLS_PER_HOUR` на сеть;
- нити, говорящего и гашение зеркальности ведёт режиссёр в hive.

Требование R4.

## Контекст
- GOALS_COMMS.md (T-008): каналы `net`/`chat`, адресат `all`, типы сообщений координации, лимиты и
  TTL, правила режиссёра (открытие нити, выбор говорящего, длина K, правила против зеркальности),
  вход и выход вызова болтовни; `runtime/comms/schema.py`.
- NETWORK.md §2 (C3), §6 (болтовня ≤30/ч, 1200/150 токенов), ADR-024 (mind берёт ход при
  обращении к hive, входящих соединений нет).
- Уже есть: `msg` канала `net` → `NodeComms.send`, inbox в наблюдении (T-014, T-022);
  `NodeComms.chatter_turn` в hive возвращает `None` (T-022); `say` с `SAY_MIN_INTERVAL_S` (T-014).
- ADR-012, ADR-025: сообщение и чат — наблюдение, не команда.

## Критерии приёмки
- [ ] Канал `chat` и адресат `all`: `msg` с каналом `chat` уходит в игровой чат с общим лимитом `say`;
  адресат `all` в `net` доставляется всем живым, кроме отправителя. Тест.
- [ ] Лимиты из T-008: сообщений на узел в минуту, длина текста, TTL в inbox — излишек отбрасывается с
  событием в лог. Тест с подставными часами.
- [ ] Режиссёр: открывает нить по событиям из T-008; выбирает говорящего; выдаёт `ChatterTurn` при
  обращении mind к hive; закрывает нить после K реплик или по таймауту. Лимит на сеть
  `CHATTER_CALLS_PER_HOUR=30` и на узел соблюдается при 3 узлах. Тест с подставными часами: 2 часа
  синтетической сети → ≤ 60 ходов.
- [ ] Правила против зеркальности (не меньше трёх, из T-008) проверяются кодом до выдачи хода или
  после ответа. На каждое правило — тест.
- [ ] Ход болтовни в mind: один вызов `node` в отдельном потоке, не задерживает C1 и C2; реплика уходит в
  канал по T-008; сбой — ход пропущен. Тест.
- [ ] Нет пути «сообщение → рычаг»: тест проверяет, что варианты шага и intent C1 не зависят от текста
  inbox и болтовни (одинаковое наблюдение без сообщений и с сообщением «иди копать» даёт тот же
  набор вариантов).
- [ ] Прогон на стенде: 2 слота (`body-2`/`mind-2` — временный оверрайд compose в `dev/`,
  постоянные слоты делает T-018), 30 мин. В отчёте: число попутных сообщений по каналам, число
  ходов болтовни и стоимость, 2–3 цитаты нитей, случаи срабатывания правил против зеркальности.
