# T-017. Общение узлов — Мисака-нет, игровой чат, болтовня с режиссёром

## Цель
Узлы обмениваются сообщениями для координации и ради разговора по ADR-022: попутно в шаге (0 вызовов)
через hive и игровой чат; болтовня — отдельные вызовы `node` в лимите `CHATTER_CALLS_PER_HOUR`,
очередь ведёт режиссёр в hive. Требование R4.

## Контекст
- После T-008 (проект), T-012 (hive), T-014 (цикл мозга). ADR-012, ADR-022.

## Критерии приёмки (предварительно)
- [ ] Поле сообщения из шага доставляется адресату в следующем наблюдении; `chat` — в игровой чат с
  лимитом частоты. Тест.
- [ ] Лимит болтовни на сеть соблюдается при 3 узлах; режиссёр обрывает нить после K реплик. Тест с
  подставными часами.
- [ ] Сообщение узла не исполняется как команда: нет пути «сообщение → рычаг». Тест.
- [ ] Прогон 3 узлов 30 мин: число вызовов болтовни и стоимость в отчёте.
