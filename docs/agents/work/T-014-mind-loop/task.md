# T-014. Цикл мозга — шаг узла C2 и тактика C1 на правилах

## Цель
Один узел живёт в мире: C1 (1–4 Гц + события) держит тело и исполняет варианты рычагами uc на
правилах (`RuleDecider`), C2 (8–15 с + события) раз в шаг зовёт LLM `node`, выбирает вариант или
подцель, говорит, шлёт `note`/`votes`/сообщения в hive. Контуры в разных потоках или задачах с
разным темпом (R6).

## Критерии приёмки (предварительно)
- [ ] C1 и C2 работают с разным темпом; C2 не блокирует C1; таймаут C2 — C1 продолжает прежнюю подцель. Тест.
- [ ] Варианты строятся из наблюдения кодом, ≤ 8–16, через ключи perception; команда уходит в uc по
  обратному переводу. Тест.
- [ ] Три сбоя LLM подряд → узел «ждёт» с растущей паузой; цикла без пауз нет. Тест.
- [ ] Промпты пишутся в отладочный лог; в `masked` тест на утечки по логу.
- [ ] Прогон на стенде 15 мин: лог решений, реплики в чате с лимитом частоты, ≥1 `note` в hive.
