# T-032. Отчёт MVP и 2-часовой прогон сети агентов

## Цель
`dev/mvp_report.py` считает критерий MVP (prototype-plan.md, пересмотр 2026-10-17) по volume `knowledge`,
`workplaces`, `run` и логу шлюза. Двухчасовой прогон трёх слотов без вмешательства проходит критерий
или даёт отчёт с причинами и задачами на исправление.

## Контекст
- Критерий MVP — `docs/agents/prototype-plan.md`, «Критерий MVP».
- NETWORK.md v2 §8 (расходы), §9 (наблюдаемость); `dev/gateway_report.py` (T-026).
- Снятая T-019 — образец структуры отчёта.

## Объём
Можно трогать:
- `dev/mvp_report.py` (новый), `tests/test_mvp_report.py` (новый)
- `docs/agents/runs/` (новый: отчёты прогонов)
- файлы задачи

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`, `.env`
- `runtime/`, `docker/`, `agent/` — дефекты идут в отчёт как предложения задач

## Критерии приёмки
- [ ] `dev/mvp_report.py` печатает и пишет markdown:
  - поколения по слотам, время жизни, причины смерти;
  - разброс черт;
  - доля новых узлов со ссылкой на предшественницу в первых 3 репликах, с цитатами;
  - смерти без `will.md`, доля аварийных;
  - перезапуски сессий раннером, зависания;
  - расход по ключам шлюза и квота, $/ч против $0.35;
  - самоправка: записи в памяти сестёр, предложения и решения Last Order;
  - служебные строки uc в логах харнесса;
  - итог PASS/FAIL по пунктам.
- [ ] Тесты на синтетических данных: PASS и FAIL по каждому пункту.
- [ ] Прогон 3 слота, 2 часа, без вмешательства; отчёт `docs/agents/runs/<дата>-mvp.md` с цитатами
  завещаний и реплик, таблицей поколений, расходом, инцидентами. Стоимость прогона ≤ $0.80.
- [ ] FAIL → по каждому пункту причина по логам и предлагаемая задача.

## Проверки
```
uv run pytest
uv run python tools/check.py
uv run python dev/mvp_report.py --knowledge <volume> --workplaces <volume> --run <volume>
```

## Ограничения
- Прогон не правит код по ходу. Повтор после аварии — с согласования оператора.
- В отчётах нет ключей и токенов.
