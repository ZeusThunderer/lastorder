# T-019. Отчёт MVP и 2-часовой прогон сети

## Цель
`dev/mvp_report.py` считает критерий MVP по volume `knowledge` и логам, а 2-часовой прогон 3 слотов
без вмешательства его проходит или даёт список причин провала.

## Контекст
- После T-013, T-016, T-017, T-018 (T-015 — по готовности). Критерий MVP — prototype-plan.md.

## Объём

## Критерии приёмки (предварительно)
- [ ] Отчёт считает: поколения, разброс черт, долю ссылок на предшественника в первых 3 репликах,
  смерти без `will.md`, утечки (`masked`) или служебные строки (`plain`) в промптах, число вызовов и
  стоимость по уровням, вызовы болтовни.
- [ ] Тест на синтетическом volume.
- [ ] Отчёт 2-часового прогона в `docs/agents/runs/`.
