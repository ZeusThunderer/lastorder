# T-073

Оператор (2026-11-11): сами стартуют только нужные контейнеры (Last Order, HAPI, доска и их
опоры); разумы поднимают Last Order, HAPI (через неё) и доска; тело — забота разума, чтобы сеть
могла сменить тело на тело другой игры. Контейнеры — по лучшим практикам. Решения оператора:
исполнитель — контейнер с сокетом Docker; `mc-server` по требованию; единица — слот целиком
(сестра + разум); тело поднимает и меняет разум. Решение — ADR-050.
