# T-058. Прогон стенда после исправлений — команда сервера, старт слота, мост, размер запроса

## Цель
Один короткий прогон на стенде подтверждает исправления T-053–T-056 на живых сёстрах.

## Контекст
- Сценарий и отчёт прошлого прогона — T-052 (`dev/board_chat_run.sh`, `docs/agents/runs/`).
- Стенд: слот 1 на внешнем сервере (`MC_SERVER_1`, пароль и запретный список — от оператора в
  `.env`), слоты 2–3 на `mc-server`. Ожидание — `dev/wait_for.sh`, без циклов sleep.

## Объём
Можно трогать:
- `docs/agents/runs/2026-11-*-fixes.md` — отчёт;
- `dev/board_chat_run.sh` — расширить под проверки ниже;
- `docs/agents/docker-topology.md` — поправки рецепта.

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`, `.env*`
- код `runtime/` — дефекты в отчёт («Вне задачи»)

## Критерии приёмки
- [ ] Вход: слот 1 на внешнем сервере входит сам (`/login` средой), пароля нет в логах
  (`grep` по логам `mind-1` и `node-1` в отчёте).
- [ ] Задача оператора с командой игрока (например `/warp …` или `/sethome`) выполнена сестрой
  через `server_command`; команда из запретного списка — отказ, сестра отвечает на доске с причиной.
- [ ] Старт слота с телом, которое было мёртвым: ложной смерти и сессии завещания нет.
- [ ] `wait_events`: ни одного вызова, убитого таймаутом харнесса.
- [ ] `dev/slot_restart.sh 2` на живом стенде: мост поднялся, сестра продолжила.
- [ ] Размер запроса: медиана и максимум входных токенов по `dev/context_report.py` — было
  (T-052) / стало.
- [ ] Расход: ходы и $ по шлюзу (`dev/gateway_report.py`), квота Z.ai — оценкой. Не дольше
  25 минут, одна жизнь на слот.

## Проверки
```
bash dev/check.sh
bash dev/board_chat_run.sh
```

## Ограничения
- Перед подъёмом сверить с оператором, не поднят ли его стенд; чужой стенд не трогать.
- Квота Z.ai общая с чатом ZCode.
- Непроверенное не выдаётся за проверенное: пометки `[проверено: …]` / `[предположение]`.
