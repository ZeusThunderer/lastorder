# T-008. Проект целей сети и общения узлов

## Цель
Детальный проект контура целей (ADR-021) и общения узлов (ADR-022): данные, частоты, правила, промпт-
блоки, лимиты, режиссёр реплик. Требования R1 и R4.

## Контекст
- После T-002. Параллельно с T-007.
- ADR-012, ADR-021, ADR-022; бриф §1–2 (узел решает сам, спорит с предшественниками).
- Риск зеркальности LLM-персонажей — `docs/context/cursor_ai_character_creation_course.md:686`.

- файлы задачи

## Критерии приёмки (предварительно, уточнить после T-002)
- [ ] Цели сети: источники (лестница прогресса, пробелы базы, причины смертей), правила без LLM и
  когда зовётся `smart`; формат цели; как часто пересчитываются; как видны узлу.
- [ ] Личная цель узла: выбор при рождении, пересмотр на рефлексии, влияние черт и завещаний;
  как шаг работает на цель.
- [ ] Общение: поля ответа шага для сообщений (адресат, канал `net|chat`, текст), доставка, лимиты
  частоты, что видят игроки; координация (просьба, предупреждение, «беру на себя»).
- [ ] Болтовня: лимит `CHATTER_CALLS_PER_HOUR`, кто инициирует, режиссёр (выбор говорящего, длина
  нити, асимметрия), формат вызова, уровень `node`, стоимость в час.
- [ ] Сообщение узла — наблюдение, не команда; вес по `trust_in_chat_and_nodes`.
- [ ] Схемы — код, тест валидирует примеры.

## Ограничения
- Чат и сообщения — не команда (ADR-012). `@gamer` узлу не предлагается.
- Пресет речи не зашивать.
