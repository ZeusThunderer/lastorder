# T-049. Страница доски для оператора — задачи, запросы, тревоги, живое обновление

## Цель
Оператор открывает `http://127.0.0.1:<порт hive>/board`, вводит пароль и видит доску сети. Он
ставит задачу узлу, `net` или Last Order, одобряет, правит или отклоняет запросы, отвечает на
`needs_input`, отмечает тревоги. Изменения видны без перезагрузки.

## Контекст
- `docs/architecture/TASKBOARD.md`, раздел 12 — страница. API под ней — раздел 9, сделан в T-042.
- Пароль — `HIVE_OPERATOR_KEY` (T-042, `dev/stand_keys.py`).
- Образец простой страницы без сборки — дашборд
  [quentintou/agent-board](https://github.com/quentintou/agent-board) (vanilla HTML/JS) — только
  как идея, код не переносить.

## Объём
Можно трогать:
- `runtime/hive/static/board.html` (+ `board.js`, `board.css` рядом) — новое
- `runtime/hive/app.py` — только отдача `GET /board` и статики, Basic-auth
- `tests/test_hive_board_page*.py`
- `docs/agents/docker-topology.md` — строка рецепта: URL и где лежит пароль
- файлы задачи

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`
- `runtime/hive/board.py` — только вопрос надзору, если API не хватает
- внешние ресурсы: CDN, шрифты, npm-сборка

## Критерии приёмки
- [ ] `GET /board` без пароля → 401 с `WWW-Authenticate`, с паролем → 200 — тест.
- [ ] В HTML и JS нет внешних URL (grep `http` в статике — только относительные пути) — тест.
- [ ] Текст агентов выводится только через `textContent`. В JS нет `innerHTML` с данными — тест
  grep'ом. Ручная проверка: запись с `<img src=x onerror=alert(1)>` видна как текст — скриншот
  в отчёте.
- [ ] Три колонки: «Задачи», «Запросы», «Тревоги и сообщения». Фильтр по адресату; мёртвые узлы
  серым.
- [ ] Действия: новая задача и сообщение; `approve`, `edit+approve`, `deny`, `respond`; отмена
  задачи; ответ на `needs_input`; `ack` тревоги. Каждое — один запрос к API T-042.
- [ ] SSE: запись, созданная `curl`'ом, появляется на открытой странице без перезагрузки —
  проверка на стенде, скриншот в отчёте.
- [ ] Стенд: `hive` + один слот без LLM-ходов. Задача со страницы видна в
  `board(filter=net)` через MCP сестры (вызов инструмента скриптом) — вывод в отчёте.

## Проверки
```
bash dev/check.sh
```
LLM-ходов в задаче нет.

## Ограничения
- Порт hive на хосте — только `127.0.0.1`.
- Пароль не в HTML, не в `localStorage` и не в URL.
- Страница ничего не решает за оператора: в ней нет автоодобрения и правил.
