# T-023. Рефлексия C4 — личная цель, core memory, кандидаты знаний

## Цель
Узел периодически осмысляет свою жизнь одним вызовом `smart`:
- при рождении выбирает личную цель (ADR-021);
- раз в 5–10 мин или по сумме важности событий переписывает core memory (≤1.5 KB);
- выдаёт ≤3 кандидата знаний со ссылками на события.

Через core memory шаг начинает работать на личную цель. Это основной путь «определения знаний» (R2)
вместе с попутным `note`.

## Критерии приёмки
- [ ] Триггеры по таблице KNOWLEDGE v2 §3:
  - первая встреча с ключом;
  - урон и от кого;
  - первое получение предмета;
  - второй подряд провал действия;
  - резкое падение hp рядом с объектом.
  Каждый получает важность и id события, на который ссылаются кандидаты. Тесты на каждый триггер.
- [ ] Расписание: окно `REFLECT_EVERY_MIN` (по умолчанию 7) или сумма важности ≥ порога T-007; не
  чаще раза в 3 мин; рефлексия идёт в своём потоке и не задерживает C1 и C2. Тест с подставными часами.
- [ ] Рефлексия рождения: сразу после `birth`, вход — черты, наследие, цели сети; выход — личная цель
  и первая core memory. Пока она не ответила, шаг идёт с пустой целью. Тест.
- [ ] Выход проверяется схемой `ReflectionOutput`: core memory режется до 1.5 KB; кандидатов ≤3, у каждого
  ссылки только на существующие события, иначе отбрасывается; `about` в формате текущего режима
  восприятия. Тест на валидный, превышающий и битый ответ.
- [ ] Отказ `smart` (таймаут, ошибка, мусор) → окно пропускается, core memory прежняя, событие в лог.
  Тест.
- [ ] Core memory → `store_core_memory`, кандидаты → `submit_candidate` с `evidence_event_ids`; оба
  вызова в `log.jsonl`, промпт и ответ — в `prompts.jsonl`. В `masked` тест на утечки по логу.
- [ ] Прогон на стенде 20 мин: ≥2 рефлексии, личная цель в `core.md` в volume `knowledge`, ≥1
  кандидат от рефлексии в базе; число вызовов `smart` и стоимость в отчёте (≤ $0.03).

## Ограничения
- Новых видов вызовов нет: рефлексия — `smart`, как в реестре NETWORK.md §6.
- Цели сети — совет, не приказ; личную цель выбирает узел.
- Черты числами в текст core memory и речь не выводятся.
