# T-081 · Доска сети Last Order

Работа выполнена в `codex/T-081-operator-board` от `f8a3bff` (T-080).

## Доска

- «Обзор» показывает по две последние записи в каждой очереди внимания и общий счётчик. История и обсуждения вынесены из обзора. Очередь исполнителя доступна через «Состояние сети».
- Выборки проверены на 207 записях новее открытого запроса. По 50 записей на страницу, курсор по ID, поиск по регистронезависимому тексту и точному `#номеру`. Поисковая строка остаётся в браузере и в теле запроса.
- Детали открываются справа, поверх списка или на мобильном экране. Решения используют актуальные права. При разрыве связи формы сохраняют текст, при конфликте сохраняют его для копирования. Поле секрета очищается при закрытии и утрате права.
- Сборщик в infra обновляет снимок раз в 10 секунд. Снимок старше 30 секунд помечается «Устарели». Состояния процесса LO, реестра, слота, тела, TTS, STT и исполнителя отображаются отдельно. Снимок процесса LO не используется как статус HAPI.

## Проверки

- 156 тестов доски, MCP, грантов, исполнителя, Compose и потокового голоса, включая таймауты сборщика и недоступный voice health. Выполнены `node --check` и `git diff --check`.
- Изолированный Chrome на 390, 768 и 1440 CSS px и при эквиваленте 200% (720 CSS px на 1440 физических пикселях). Проверены фокус и возврат к строке, отсутствие горизонтальной прокрутки, ограничение строки двумя линиями и показ 800-символьного текста в деталях. Наименьший измеренный контраст обычного текста 5,56:1.
- На тестовых данных пройдены поиск и подтверждение тревоги, секретный грант, явный выбор LO, исчезновение адресата, сохранение ввода при разрыве связи, двойная отправка и конфликт статуса. Мониторинг проверен на остановленном слоте, недоступном голосе, занятом исполнителе и устаревшем снимке.

Снимки на тестовых данных: [обзор](board-overview.png), [детали](board-detail.png), [мобильный обзор](board-mobile.png), [мобильные детали](board-mobile-detail.png).

## Стенд

- Развёртывание под блокировкой T-081 из отдельного worktree. Собраны слои поверх локальных образов hive, infra и TTS. Очередь исполнения перед запуском infra была пуста.
- `/board` отвечает 200. Hive и infra проходят healthcheck. Защищённый `/board/status` возвращает свежий снимок с доступным Docker и работающим исполнителем. LO, HAPI, игровой мир и слоты были остановлены до работы и оставлены в этом состоянии.
- Voice health и живой снимок доски подтверждают готовность faster Qwen и Whisper на RTX 2070. Одна локальная HTTP-проба дала первый блок за 1,36 с и 268 800 байт PCM 48 кГц. Whisper вернул «Провирка голоса. Слышно хорошо?». Игровой тракт в этом прогоне был остановлен.
- На холодном запуске `float16` из локального `.env` вызвал CUDA-ошибку `probability tensor ... inf, nan`. Развёрнут рабочий `float32` из T-080. Для пересоздания voice из этого worktree использовалась команда `TTS_DTYPE=float32 bash docker/node/up.sh --no-build --pull never --no-deps tts`.

Для повторного развёртывания этой версии используется Compose из worktree T-081. Исходный проект Docker, имена томов и корневой каталог стенда сохранены.

## Переработка после проверки оператором

На главном экране расположены задачи, запросы и события. Каждый раздел показывает до четырёх записей с приоритетом требующих внимания. На телефоне разделы идут вертикально, сверху доступны переходы со счётчиками. Обсуждение раскрывается под выбранной записью, форма создания встроена в страницу. Палитра использует тёмно-синий, холодный белый, голубой и жёлтый из постера Index.

Прошли 52 теста API и страницы и браузерный сценарий на 1440 и 390 px. [Компьютер](streams-desktop.png) · [Телефон](streams-mobile.png).

## Японская журнальная вёрстка и открытый выбор

В шапке использован портрет LO из character-LO-v1, указанного в манифесте персонажей. Фильтры и форма создания используют подписанные группы радиокнопок. На широком экране сохранены три параллельных потока, на телефоне — одна лента с переходами. Обсуждение раскрывается под выбранной записью.

Проверено на тестовых данных в Chrome при ширине 1440 и 390 px: обзор, раскрытие обсуждения, выбор LO, смена вида записи на сообщение всей сети, выбор адресата в фильтре. Снимки — edition-desktop.png и edition-mobile.png. Тесты board и board_page: 52 прошли. На стенде обновлён hive, контейнер healthy, HTTP отдаёт новую разметку и портрет.
