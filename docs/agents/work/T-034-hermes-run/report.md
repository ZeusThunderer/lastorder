### Вне задачи (предложения задач)
- П-1 (docker/) — список сервисов прогона узла неполон без `zai-egress` (и `llm-gateway` при
  failover): закрепить в документации запуска стенда или depends_on у node.
- П-2 (runtime/hive, из C-4) — `submit_will` требует X-Node-Key и в dev-open: на стенде без
  ключей путь воли агента недемонстрируем (2 аварийных завещания при готовом тексте воли).
  Предложение: ключи HIVE_*_KEY_N в .env стенда (оператор) или явный dev-open приём воли.
- П-3 (runtime/node) — расход detached-gateway невидим раннеру: при аварии CLI умер с конвертом
  «total: 0», а гейтвей довёл сессию на 1,28M токенов; учёт квоты по state.db/usage, не по
  конверту CLI.
- П-4 (docker/) — `restart: unless-stopped` поднимает стенд при старте Docker Desktop без
  надзора и жжёт квоту (утренний инцидент, узел 77): для прогонов — `restart: no` или скрипт.
