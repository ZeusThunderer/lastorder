# T-056. Контекст запроса сестры — разбор 100k токенов и сокращение главных частей

## Цель
Запрос сестры к модели становится заметно меньше, и сеть отвечает быстрее. Есть отчёт, из чего
состоит запрос, и сокращены самые крупные части. Поведение сестры не меняется.

## Контекст
- Замер надзора по логам model-io zcode (13:50–14:07, 2026-10-31): медиана запроса ≈100k входных
  токенов, 6–8 с, хвост до 175 с; 78–95 % времени сестра ждёт модель
  [источник: отчёт T-052, «Для lo-plan»].
- Инструкции сестры (`agent/last_order/*.md`) — около 19 тыс. символов, то есть порядка 5–6k
  токенов [проверено: `wc -c`, 2026-10-31]. Значит, основная часть — системный промпт харнесса,
  схемы инструментов и накопленный вывод инструментов в сессии [предположение, проверить].
- Описания инструментов MCP тела — `runtime/mind/mcp_body.py:420-470`; MCP hive — `runtime/hive/`.
- Харнесс сестёр сейчас zcode; переход на Pi — T-045. Рычаги этой задачи не должны зависеть
  от харнесса: вывод инструментов, описания, инструкции. Настройки сжатия сессии конкретного
  харнесса — только описать.

## Объём
Можно трогать:
- `dev/context_report.py` — новый: разбор запросов из логов model-io (и логов шлюза, если там есть
  тела запросов) по частям: системный промпт, схемы инструментов, история, вывод инструментов
  по имени инструмента;
- `runtime/mind/mcp_body.py` — размер ответов инструментов (лимиты, сжатие повторов, без потери
  полей, которыми пользуется сестра); описания инструментов;
- `runtime/hive/mcp*.py` — то же для MCP hive (критичная зона: не трогать запись базы);
- `agent/last_order/AGENTS.md`, `SESSION_PROMPT.md` — сжатие без потери правил; ядро
  `prompt_template.md` не трогать;
- `tests/`, `docs/agents/runs/2026-11-*-context.md` — отчёт.

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`, `.env*`, `agent/last_order/prompt_template.md`
- `runtime/perception/` — нормализация имён остаётся как есть

## Критерии приёмки
- [ ] `dev/context_report.py` на логах сессии T-052 печатает долю каждой части в медианном и
  максимальном запросе. Таблица — в отчёте, с путём к логам.
- [ ] Три самые крупные части, на которые влияет код или инструкции проекта, сокращены. Для
  каждой — было/стало в токенах (по скрипту на синтетической сессии или на тех же логах после
  пересчёта) и почему смысл не потерян.
- [ ] Ответы инструментов MCP тела имеют предел размера; тест на самый крупный ответ.
- [ ] Части, на которые проект не влияет (системный промпт харнесса и т. п.), названы с размером;
  что даёт настройка харнесса — описано, не сделано.
- [ ] Оценка: ожидаемая медиана запроса после правок [предположение]. Живой замер — в T-058.
- [ ] `bash dev/check.sh` и `python tools/check.py` зелёные.
