# T-016. Контур целей сети в hive (C5) и консолидация

## Цель
Hive раз в несколько минут пересчитывает 1–3 цели сети: правила по сигналам из базы и смертей плюс
редкий вызов `smart`. Цели попадают в `KnowledgeSlice.network_goals`; узел видит их как совет и
учитывает при выборе личной цели (T-023). Тот же медленный контур делает консолидацию базы по
правилам. Требование R1, контур сети в R6.

## Контекст
- GOALS_COMMS.md (T-008): сигналы, таблица «сигнал → цель», лестница прогресса, срок жизни цели,
  вход и выход `smart`, лимит ≤4/ч на сеть; `runtime/hive/goals_schema.py`.
- NETWORK.md §2 (C5: сбой smart → правила, окно пропускается), §6 (цели и консолидация 4/ч, 5000/800
  токенов).
- KNOWLEDGE.md v2 (T-007): консолидация MVP — дедуп, статусы, голоса (LLM-консолидатор — позже).
- Hive: `runtime/hive/app.py`, `runtime/knowledge/store.py` (T-012, T-022). Рефлексия рождения
  получает цели через `knowledge()` (T-023).
- ADR-021: совет, не приказ; ADR-023: уровень `smart`.

## Объём
Можно трогать:
- `runtime/hive/goals.py`, `runtime/hive/council.py` (новые: расписание C5, правила, вызов `smart`)
- `runtime/hive/app.py` — запуск фоновой задачи
- `runtime/knowledge/store.py` — только хранение целей (`goals.json` под git) и выдача в срезе
- `agent/last_order/council_prompt.md` (новый: промпт совета сети, на английском, ответ по-русски)
- `tests/test_goals.py`, `tests/test_council.py` (новые)
- файлы задачи

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`
- `runtime/mind/` — узел уже получает цели через срез; изменения поведения узла — в отчёт

## Критерии приёмки
- [ ] Сигналы считаются из базы и реестра без LLM: ступень лестницы прогресса, пробелы базы, топ причин
  смертей за окно. Тест на синтетической базе на каждую ступень и сигнал.
- [ ] Правила дают 1–3 цели с `why`; одинаковые сигналы — одинаковые цели (детерминизм). Тест.
- [ ] `smart` вызывается, только если правила дали меньше 1 цели или сигналы противоречат друг другу
  (точное условие — из T-008), и не чаще `COUNCIL_SMART_PER_HOUR` (по умолчанию 4). Тест с подставными
  часами: за 2 часа ≤ 8 вызовов.
- [ ] Сбой `smart` или битый ответ → цели по правилам, иначе прежние; событие в лог hive. Тест.
- [ ] Цели пишутся в базу одним коммитом `goals: …` и попадают в `knowledge()` всех узлов. Тест.
- [ ] Консолидация по расписанию: повторный дедуп записей, пересчёт статусов по голосам, `retired` по
  правилам T-007 — один коммит на проход, если есть изменения. Тест.
- [ ] Прогон на стенде 30 мин с одним узлом: история целей (`git log goals.json`), вызовы `smart` и их
  стоимость, цитата блока «совет сети» из `prompts.jsonl`, личная цель из `core.md`.

## Проверки
```
uv run pytest
uv run python tools/check.py
docker compose -f docker/compose.yml up -d mc-server hive body-1 mind-1
```

## Ограничения
- Цели сети — совет; в варианты шага они не превращаются, телом не управляют.
- Пишет базу только hive. Новых видов вызовов нет: цели и консолидация — `smart` в лимите.
