# T-016. Контур целей сети в hive (C5)

## Цель
Hive раз в N минут пересчитывает 1–3 цели сети по правилам и, если нужно, редким вызовом `smart`;
цели попадают в контекст узлов как совет. Узел выбирает и пересматривает личную цель. Требование R1.

## Контекст
- После T-008 (проект), T-012 (hive), T-014 (цикл мозга). ADR-021.

## Объём
Можно трогать:
- `runtime/hive/goals.py`, `runtime/hive/` — подключение; `runtime/lastorder/` — личная цель
- `tests/test_goals_*.py`
- файлы задачи

## Критерии приёмки (предварительно)
- [ ] Правила целей работают без LLM; вызов `smart` не чаще лимита из T-008. Тест с подставными часами.
- [ ] Цель сети видна узлу в промпте как совет; личная цель записана в core memory и в лог. Тест.
- [ ] Сбой `smart` — прежние цели остаются. Тест.
