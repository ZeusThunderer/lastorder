# T-067. Ролик-знакомство с Last Order — персонаж, сеть сестёр, кадры игры

Исполнитель — надзор (Claude Code) вместе с оператором. ZCode задачу не берёт (`owner: supervisor`).
Срок — до занятия 2026-11-07.

## Цель
Готов ролик 60–120 с, который знакомит зрителя курса с персонажем: кто такая Last Order, что такое
сеть сестёр, как узел живёт, умирает, оставляет завещание и как следующий читает базу. В ролике есть
настоящие кадры игры со стенда, а не только схемы. Сборка повторяется одной командой из исходников.

- Персонаж: docs/character/LAST_ORDER.md (источник истины), ядро — agent/last_order/prompt_template.md.
- Конвейер, монтажный лист, проверки: docs/agents/video-toolkit.md §3, §5, §6.
- Скин: agent/last_order/skin/ (`preview.png`, `sister.png`).
- Реальный материал прогонов (реплики, завещания, цифры): docs/agents/runs/2026-10-23-mvp.md,
  2026-10-24-mvp-2.md, 2026-10-31-board-chat.md; что сделано — task3-4.md.
- Камера тела в среде ещё не готова (T-063, T-065), поэтому кадры снимаются вручную.
- На хосте есть ffmpeg 9.0.2 и OBS (`C:\Program Files\obs-studio`) [проверено: 2026-11-07].
- Стенд `lastorder-*` запущен, но сёстры (node-N) остановлены; mc-server на порту хоста 25565
  (docker/compose.yml:165).

## План
1. **Монтажный лист** `edit.md` (формат video-toolkit.md §5): эпизоды «кто она» → «сеть сестёр» →
   «жизнь узла в игре» → «смерть и завещание» → «следующий узел и база» → «оператор: чат и доска» →
   финал. На каждый эпизод — картинка, текст или голос, источник, проверка. Оператор правит лист
   до съёмки.
2. **Съёмка игры.** Основной путь: OBS на хосте пишет обычный клиент Minecraft в режиме наблюдателя
   на сервере стенда, пока 1–2 сестры живут. Запасной путь: экран тела из Xvfb (`BODY_RENDER=xvfb`)
   через ffmpeg `x11grab`. Рядом пишутся журналы прогона (`events.jsonl` hive, `log.jsonl` mind-N),
   чтобы подписи сверять с ними.
3. **Экраны интерфейсов:** чат HAPI с Last Order, страница доски, лента событий hive. Это короткие
   записи экрана OBS.
4. **Плашки и титры** — HTML/CSS, рендер в PNG или короткие клипы. Имя узла по пресету из конфига,
   черты числами не показываются.
5. **Сборка** скриптом `dev/video/build_intro.sh` на ffmpeg: нарезка, плашки, субтитры, `loudnorm`.
   Исходники и рендеры лежат вне git (`dev/video/out/`, в `.gitignore`).
6. **Проверка** по video-toolkit.md §6: лист кадров (`tile`), стыки, подписи сверены с журналом,
   в кадре нет `[Alto Clef]`, `[Tungsten]` и сырых id.

## Открытые вопросы оператору
По умолчанию, если оператор не ответит:
- язык и звук: русские субтитры, звук игры, без закадрового голоса (TTS ещё не построен, ADR-009);
- зритель: участники курса и преподаватель;
- запуск сестёр для съёмки тратит ту же квоту Z.ai, что и ZCode: снимать 1–2 сестры 15–20 мин,
  когда ZCode не работает;
- пресет имени в плашках: `lab` («узел 00007»), он сейчас по умолчанию.

## Ограничения
- Новые расходы (облачный TTS, генерация, распознавание) — только с согласования (CLAUDE.md, ADR-033).
- Имя узла — пресет, не зашивать ни один из них в плашки скрипта: брать из конфига или параметра.
- Черты числами не выводятся; служебные строки uc зрителю не показываются (ADR-037).
- Установку программ оператор делает сам по инструкции надзора.
