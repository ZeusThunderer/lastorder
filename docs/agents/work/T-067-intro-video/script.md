# T-067. Режиссёрский сценарий ролика-знакомства · v1 2026-11-07

Монтажный лист эпизодов — [edit.md](edit.md); здесь — стиль, покадровый сценарий с таймкодами,
раскадровка и план работ. Решение оператора 2026-11-07: снимать систему такой, какая она есть
сейчас, по правилам video-toolkit.md; для съёмки — отдельный контейнер-наблюдатель с высокой
детализацией (`docker/compose.camera.yml`).

## 1. Замысел

**Логлайн.** В одном мире Minecraft живут сёстры — короткие жизни одного разума. Каждая
рождается с номером, играет, умирает и оставляет завещание следующей. Ролик показывает один такой
круг на настоящих кадрах и настоящих записях стенда.

**Зритель.** Участники курса и преподаватель: знают, что такое LLM-агент, не знают проект.

**Что зритель должен унести (три мысли).**
1. Сестра — агент, который сам решает, что делать; код только тело и страховки.
2. Смерть — передача смены: завещание пишется, следующая читает.
3. Это работает сейчас, с дефектами, и ролик их не прячет.

**Длительность** 100 с (допуск 60–120). 1920×1080, 30 к/с, H.264 + AAC, `loudnorm` −14 LUFS.

## 2. Стиль: «журнал наблюдения»

Персонаж говорит «сухо, как лабораторный отчёт» (LAST_ORDER.md §2). Ролик снят так же: это
запись наблюдения за сетью, а не трейлер.

| Элемент | Решение |
|---|---|
| Камера | Наблюдатель-призрак. Три плана: **общий** (неподвижная камера в 5–7 блоках, смотрит на сестру), **за спиной** (третье лицо), **глазами** (первое лицо). Движения камеры нет, есть смена планов. |
| Монтаж | Жёсткие склейки внутри эпизода; между эпизодами — затемнение 8 кадров. Средний план 3–5 с. |
| Плашки | Графитовый фон `#17181d`, моноширинный Cascadia Mono. Заголовок плашки — строка журнала: `2026-11-07T17:30:06Z  life.birth  serial=00160`. |
| Цвета | Белый `#e8e8ea` — текст; зелёный `#3fd37a` (линза очков сестры со скина) — номер узла и говорящий; янтарный `#f0a040` — смерть и аварийное; серый `#8a8d96` — служебное. |
| Значок записи | Во время кадров игры, левый верхний угол: `● REC  LastOrder01 · узел 00160 · 17:31:02Z` (время — UTC из журнала съёмки). |
| Субтитры | Segoe UI Semibold, 46 px, белые на плашке 60 % чёрного, внизу по центру, до двух строк. Перед репликой — имя по пресету зелёным: «узел 00160:». Скорость чтения ≤ 15 зн/с. |
| Звук | Только звук игры с камеры (шаги, удары, мобы). Музыки нет (новые расходы и лицензии — не нужны). Под плашками звук игры приглушён до −18 дБ. |
| Имя узла | Пресет из конфига стенда (сейчас `lab`): «узел 00160». Скрипт сборки берёт пресет параметром. |
| Нельзя в кадре | Строки `[Alto Clef]`, `[Tungsten]`, сырые id, черты числами, токены. Чат игры на камере выключен (`chatVisibility:2`): реплики — только субтитрами из журнала. |

## 4. Раскадровка

Кадры — настоящие снимки камеры-наблюдателя и отрендеренные плашки:
`dev/video/out/storyboard/` (вне git), сводный лист — [storyboard.jpg](storyboard.jpg).
Лист собирается после съёмки (`bash dev/video/storyboard.sh`), по кадру на строку сценария.

## 5. План работ

1. **Съёмка** — take1: 20 мин, сёстры в слотах 1–2, автор-режиссёр `dev/video/direct.sh`
   (план меняется каждые 45 с, журнал склеек `take1.shots.jsonl` с UTC). Рядом пишутся журналы
   `node-N` и сессии Pi. Смерть в кадре не гарантирована: если её нет — эпизод 5 строится на
   журнале и завещании 00157.
2. **Черновой монтаж** — `dev/video/build_intro.sh`: нарезка по таймкодам из `cut.json`, плашки
   HTML → PNG (Edge headless), субтитры ASS, сборка ffmpeg.
3. **Проверка** — video-toolkit.md §6: лист кадров (`tile`), реплики сверены с журналом, нет
   служебных строк и чисел черт, длительность и формат `ffprobe`.
4. **Исправление** найденного.
5. **Чистовой монтаж** — повторная сборка одной командой, отчёт `report.md`.
