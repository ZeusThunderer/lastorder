# T-030. Last Order — агент-администратор сети по событиям

## Цель
В hive живёт агент Last Order (ADR-036). Он просыпается по событиям: смерть и завещание, пачка
предложений, сообщение оператора, раз в N минут. Решает по предложениям, ведёт цели сети и летопись,
отвечает сёстрам. Оператор добавляет цели через его `GOALS.md`.

## Контекст
- ADR-021, 030, 034, 036; NETWORK.md v2 §2, §7.
- Инструменты Last Order — T-028; харнесс и адаптеры — T-024, T-027 (`runtime/node/`).
- Источник правил для инструкций (не код): GOALS_COMMS.md §1 (сигналы, лестница прогресса),
  KNOWLEDGE.md v2 §4 (согласование).

## Критерии приёмки
- [ ] Будильник: события смерти, N предложений в очереди, сообщение оператора, таймер; одновременно одна
  сессия; события во время сессии копятся. Тест с подставными часами.
- [ ] Короткая сессия Last Order: читает очередь и сводку, решает, пишет память в своём рабочем месте.
  Модель `smart` через шлюз.
- [ ] Инструкции Last Order: критерии принятия знаний и навыков, ведение 1–3 целей сети, летопись,
  тон ответов сёстрам; общие инструкции сети правит сам, ядро — нет.
- [ ] Цели оператора из `GOALS.md` попадают в цели сети с пометкой автора.
- [ ] Прогон с T-027 (1–3 слота, 30 мин): ≥1 решение по предложению, цели сети обновлены, запись
  летописи; число сессий и стоимость.
