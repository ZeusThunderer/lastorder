# T-035. Ревью надзора

## Ответ 1 · 2026-10-24 · headless

**Вопрос (Раунд 1):** в hermes-venv образа нет пакета `mcp`, критерий 3 невыполним без правки
`docker/node/Dockerfile`, а `docker/` в «Нельзя трогать».

**Ответ:** вариант 1. Это не эскалация: расширение «Можно трогать» без пересечения с задачами
в работе (T-037 меняет только `docker/compose.yml`, T-039 `docker/` не трогает). Сетевую политику
ADR-033 правка не меняет: SDK ставится при сборке, egress песочницы остаётся прежним.
- «Можно трогать» расширено: `docker/node/Dockerfile`, только слой hermes. Добавить extra `mcp`
  в `uv sync --frozen --no-dev --python 3.14` (`--extra mcp`) и одну строку комментария, зачем он нужен.
  Остальные extras не подключать.
- `--frozen` требует, чтобы extra был в `uv.lock` upstream. Если `uv sync` откажет, не снимай
  `--frozen` и не ставь `mcp` отдельным `uv pip install` без пина. Запиши вывод и вернись вопросом.
- Пересобери образ `lastorder-node:dev` (`docker compose build node-1` или как в `up.sh`).
  `down`, `docker volume` и `docker system` не трогать.
- Добавь проверку в отчёт: `docker run --rm --entrypoint /opt/hermes/bin/python lastorder-node:dev -c "import mcp"`
  (или `-I -c` из venv) — без ошибки.
- Стенд: после пересборки разрешены ещё до двух сессий. Цель — одна oneshot с тем же промптом,
  что в Раунде 1. Критерий 3 остаётся в прежней формулировке: вызов `observe()` тела и список
  инструментов hive. В dev-open вызов hive отвечает «unknown node key», так и запиши. Укажи,
  как инструменты видны модели: сразу или через `tool_search`.
- Обход SIGSTOP раннера в отчёте описан, это приемлемо. В следующем раунде перечисли, какие
  контейнеры остановлены после проверки.
