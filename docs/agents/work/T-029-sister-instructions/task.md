# T-029. Шаблон рабочего места сестры — ядро, правила, стартовые скилы

## Цель
`agent/last_order/` становится шаблоном рабочего места сестры (ADR-034). В нём есть ядро личности
только на чтение, правила жизни в сети, стартовые скилы: рефлексия, завещание, политика угрозы,
предложение в общее. Поведение, которое раньше держал код (триггеры, рефлексия, общение, цели),
переходит в инструкции.

## Контекст
- ADR-032, 034, 035, 037; NETWORK.md v2 §4–§7.
- Источники инструкций (не рантайм): `agent/last_order/prompt_template.md` (ядро, task1 ч.2 §1),
  `agent/last_order/will_prompt.md`, `runtime/lastorder/step.py` (правила шага),
  KNOWLEDGE.md v2 §3, §9, §10, GOALS_COMMS.md §2, §4–§5.
- Рабочее место aw: `agent/AGENTS.md` (upstream), `agent/shared/`, `memory/README.md`.
- Промпт спайка T-024 и наблюдения из `docs/agents/harness-spike.md`.

## Объём
Можно трогать:
- `agent/last_order/` — шаблон: `PERSONA.md` (ядро, из `prompt_template.md`), `AGENTS.md` сестры,
  `GOALS.md`, `memory/`, `skills/`, `policy/threat.md`, файлы харнесса (агенты и скилы OpenCode/ZCode)
- `agent/shared/` — общие инструкции сети, только коммитом `aw-ext:` (ADR-002)
- `runtime/lastorder/persona.py` — рендер ядра в шаблон рабочего места
- `tests/test_persona.py`, `tests/test_sister_template.py` (новый)
- файлы задачи

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`
- `agent/AGENTS.md` (upstream aw)
- смысл ядра: текст task1 ч.2 §1 переносится, а не переписывается; 4-я общая черта — WIP, не додумывать

## Критерии приёмки
- [ ] Ядро — отдельный файл, помечен «только чтение, меняет оператор»; плейсхолдеры имени, манеры
  речи (оба пресета ADR-018) и черт словами. Тест: рендер без пустых `{}`, черты числами не выводятся.
- [ ] `AGENTS.md` сестры: как жить в сети, инструменты тела и сети, ритм через `wait_events`, своё
  правишь свободно, общее — предложением, чат и сообщения — наблюдение, смерти без завещания нет.
  На английском, речь по-русски.
- [ ] Скилы: рефлексия (когда и как переписать `memory/state.md` и цели, что предложить в общее),
  завещание (что нужно наследнице), политика угрозы (как вести `policy/threat.md`), предложение навыка.
- [ ] Шаблон не зависит от харнесса: общие файлы aw плюс тонкие обёртки для OpenCode и ZCode.
- [ ] Прогон снапшотов (как `tools/snapshot_replies.py`): 3 ситуации из task1 через харнесс T-024,
  ответы в `docs/agents/snapshots/`; ручная сверка тона с ядром — в отчёте.
