# T-031. Jev в C1 по текстовой политике сестры

## Цель
C1 при угрозе зовёт облачный Jev (ADR-027) через шлюз. На вход идут компактное состояние, под-варианты
и политика `policy/threat.md` из рабочего места сестры. При таймауте или ошибке работают правила.
Политику пишет агент, код её не толкует.

## Контекст
- ADR-027, 035; NETWORK.md v2 §2 (политика тактики), §5.
- Снятая T-015: шаги замера облачного Jev, `dev/jev_spike.py`, протокол FastJev (`docker/jev/`),
  `docs/agents/jev.md`.
- Исполнитель C1 — T-025 (`runtime/mind/`); шлюз — T-026.

## Объём
Можно трогать:
- `runtime/mind/jev.py` (новый), подключение в исполнителе C1
- `dev/jev_cloud_probe.py` (новый), `docs/agents/jev.md` — раздел про облачный Jev
- `docker/compose.yml` — env `JEV_*` для `mind-N`
- `tests/test_jev_policy.py` (новый)
- файлы задачи

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`, `.env`, `docker/jev/`

## Критерии приёмки
- [ ] Замер: 100 решений на синтетических состояниях с политикой и без, p50/p95 с этого хоста, токены,
  стоимость (≤ $0.05). Таймаут C1 и пол — по цифрам, итог в `jev.md`.
- [ ] Политика читается из рабочего места по пути из конфига, обрезается по длине; нет файла — без
  политики. Тест.
- [ ] `JEV_BACKEND=cloud|local|rules`; таймаут или ошибка → правила и `jev.fallback` в `log.jsonl`. Тест.
- [ ] Пол `JEV_MIN_INTERVAL_S` на узел. Тест с подставными часами.
- [ ] Прогон 15 мин `cloud` против `rules`: смерти, уклонения, доля откатов, стоимость.

## Проверки
```
uv run pytest
uv run python tools/check.py
uv run python dev/jev_cloud_probe.py --n 100 --max-usd 0.05
```

## Ограничения
- Jev выбирает только среди под-вариантов кода; `@gamer` нет. Ключ — только через шлюз.
