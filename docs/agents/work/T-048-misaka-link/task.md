# T-048. misaka-link — расширение Pi доставляет доску, Мисака-нет и события сети в живую сессию

## Цель
Есть расширение Pi `misaka-link`. Это наша среда, а не инструмент-возможность. Оно забирает из
hive записи доски своего агента и `net`, сообщения Мисака-нет и события сети и кладёт их в
живую сессию Pi под `hapi pi`. Агент отличает голос оператора из HAPI, записи доски и события
среды друг от друга.

## Контекст
- ADR-042: ввод оператора — чат HAPI (голос, наблюдение) и доска (задача — сильная просьба).
  «Мысли» нет. Сестра под `hapi pi` (T-044): stdin Pi держит HAPI, поэтому среда доставляет
  сообщения в сессию только расширением.
- Доставка [проверено: T-041 отчёт, критерий 4]:
  - `steer` — после ближайшего вызова инструмента, пока агент работает;
  - `follow_up` — когда агент свободен.

  В расширении это API отправки сообщения пользователя с режимом доставки
  [источник: pi docs/extensions.md — сверить на Pi 1.4.0].
- `pi.sendMessage` кладёт запись `role: custom` [проверено: T-041 session5]. Для событий среды
  этого достаточно, если модель её видит и сессия просыпается — проверить.
- Лента доски — `GET /board/feed` и SSE (T-042); Мисака-нет — `/comms/inbox`
  (`runtime/hive/app.py:518`).
- Метка ввода оператора — ответ на вопрос 6 из отчёта T-044.
- Расширение T-041 `dev/console_spike/thought.ts` — образец загрузки, не код для переноса.

## Объём
Можно трогать:
- `runtime/pi/misaka-link/` — новое расширение (TypeScript), тесты (`node --test`),
  `package.json` без сетевых зависимостей в рантайме
- `runtime/node/workplace.py` — только добавить `misaka-link` в каталог расширений
  `drop_pi_agent_dir`
- `runtime/hive/app.py` — только курсор чтения ленты на агента, если T-042 его не дал
- тесты отрисовки (`tests/test_node_workplace*.py` или текущие)
- файлы задачи

Нельзя трогать:
- `unionclef/`, `NetTyan/`, `task1.md`
- `runtime/node/adapters.py`, `runtime/node/runner.py` (T-045), `runtime/hive/admin.py` (T-043)
- `agent/` — инструкции пишут T-043 и T-045

## Критерии приёмки
- [ ] Новая запись доски агента или `net`:
  - агент свободен — доставка `follow_up`, агент просыпается;
  - агент работает — доставка `steer`.

  Тест на записанном обмене или фейковом API Pi.
- [ ] Каждая запись доставляется один раз, в том числе после перезапуска расширения
  (курсор в hive) — тест.
- [ ] Конверт доставки различает источники: `board-task`, `board-request` (ответ на запрос
  агента), `net-message`, `event`. Ввод оператора из HAPI агент отличает от сообщений среды —
  тест.
- [ ] Hive недоступен: сессия не падает, ошибка — в журнале расширения, повтор с паузой — тест.
- [ ] Живая проверка в `node-1` под `hapi pi`:
  - задача оператора с доски доходит до агента;
  - агент отвечает на доске (`reply`);
  - сообщение оператора из HAPI агент называет сообщением оператора.

  Выводы — в отчёте.

## Ограничения
- Расширение только доставляет; инструментов-возможностей не добавлять (ADR-041).
- Голос и задачи оператора — не приказ; в расширении нет правил поведения (ADR-032).
- Служебные строки uc и сырые id агенту не показываются.
- Новых выходов из `node-N` нет: только hive.
