# T-078. Постоянные личности линий и эталоны персонажей

## Цель
Реализовать утверждённый оператором в чате 2026-11-17 план: постоянное ядро слота,
лоровые манеры LO и сестёр, медленное развитие по опыту, эталоны внешности.
Оператор передал Codex роль надзора и исполнителя вместо Claude Code.

## Решения оператора
- Первое лицо, женская грамматика; LO и сестра с серийным номером, без «Мисака».
- Полный случайный переброс черт снять. Личность линии сохраняется между сменами.
- Сохранить культуру сети; канон Toaru задаёт манеры, не вымышленные воспоминания.
- Начальные отличия образов малы, развитие очень медленное; сёстры сами предлагают
  изменения в рамках, LO проверяет, крупные изменения решает оператор.
- LO младше сестёр: три варианта полноценной одежды с полосатой кофтой и архивными
  мотивами. После выбора оператора — финальные эталоны и включение развития.
- Пет, провайдеры, оплата, мир и старые архивы не меняются.

## Ограничения
- Отдельный worktree. Незакоммиченные изменения main не переносить и не перетирать.
- Поведение только в данных и инструкциях; раннер лишь выбирает профиль и переносит его.
- Общая база меняется через существующий hive. Ядра остаются защищёнными.
- Не сбрасывать текущую смену; новый профиль со следующего рождения.
- Никаких субагентов и вызовов отсутствующего Claude.

## Приёмка и проверки
- Два рождения одного слота имеют одинаковые базовые черты; разные слоты различимы.
- Исторические записи/воли читаются, перезапуск не меняет профиль.
- Эволюция доставляется наследнице, не может подменить операторское ядро.
- Русское первое лицо, женская грамматика; инструкции согласованы.
- Три варианта LO показаны; выбор, эталоны, генератор и диалоговые пробы отражены
  честно в report.md, без отметки готовности до реальной проверки.
- uv run pytest; python tools/check.py; целевые тесты по ходу.
