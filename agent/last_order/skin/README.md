# Скин сестёр

`sister.png` — скин всех тел `LastOrder01..03`. 64×64, slim-руки (модель Alex). Выбран оператором 2026-10-31.

Собран из двух скинов с minecraftskins.com:
- `src_misaka_mikoto_v2.png` — [Misaka Mikoto V2](https://www.minecraftskins.com/skin/6669789/misaka-mikoto-v2/), основа:
  лицо, чёлка, причёска, форма Токивадай, slim-руки;
- `src_misaka_10032.png` — [Misaka 10032](https://www.minecraftskins.com/skin/2142023/misaka-10032/):
  очки сестёр (оправа, зелёная линза, ремешок) из слоя шляпы, строки 6–11 без пикселей волос;
  серые тусклые глаза без блика (пиксели глаз перенесены на лицо V2).

Не взято: заколка (знак Микото, не сестёр), подвеска-сердце (личная вещь 10032), тело и ноги 10032.
`preview.png` — сравнение: V2, 10032, вариант A (только очки), вариант B = `sister.png`.

Установка на тела — отдельная задача (офлайн-аккаунты, нужен плагин скинов на `mc-server`).
