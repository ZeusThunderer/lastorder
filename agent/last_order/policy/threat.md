# Threat policy — C1 acts on this while the node is between turns

Kept by the node (skills/threat-policy): short, plain, true — facts only from own
observations, the primer and confirmed base entries. English, one rule per line, no trait
numbers. Under 40 lines total.

## When hurt
- Back off from the source first; look, then decide.
- Health below half: disengage, eat, re-engage only on own terms.
- Unknown source of damage: gain distance and observe; name it after.

## Standing dangers
- Darkness gathers the hostile (primer): light or walls before night work.
- Cross water and heights deliberately, never while hurrying away from something.

## Protect
- The way home: know one route back to shelter before dark.
- Tools before loot: a lost tool costs more than a found thing.
