# lo-take — взять задачу

Если ты не ZCode (worker) — остановись, этот скил не для тебя.

Протокол: `docs/agents/coop-protocol.md`. Правила проекта: `CLAUDE.md` — прочитай, если ещё не читал
в этой сессии.

## Шаги
1. Открой `docs/agents/work/T-NNN-*/task.md`. Статус должен быть `ready` или `changes`.
   Иначе сообщи пользователю статус и остановись.
2. Рабочее дерево должно быть чистым (`git status`). Если нет — спроси пользователя, ничего не удаляй.
3. Ветка:
   - `ready`: `git switch main`, затем `git switch -c z/T-NNN-<slug>` (имя ветки — из `branch` задачи);
   - `changes`: `git switch z/T-NNN-<slug>`, затем `git merge main`, если `main` ушёл вперёд.
4. При `changes` прочитай последний раунд `review.md` и раздел «Заметки надзора» в `task.md`.
   Правки надзора из заметок уже в ветке — не перетирай их.
5. Поставь `status: in_progress` во frontmatter `task.md`. BOARD не трогай: он в `main`, его ведёт надзор.
6. Работай строго в пределах «Можно трогать»:
   - тесты на каждое поведение из критериев приёмки;
   - файлы upstream aw (`agent/AGENTS.md`, `agent/shared`, `agent/scripts`, `tools/`) — отдельными
     коммитами с префиксом `aw-fix:` / `aw-ext:`;
   - остальное — `T-NNN: <суть по-английски>`;
   - в конце каждого коммита трейлер `Agent: zcode`.
7. Для нетривиальной некритичной задачи можно до кода показать план надзору: `lo-call-supervisor`, режим plan.
8. Задача неясна или противоречит CLAUDE.md / ADR — `lo-blocked`. Готово — `lo-submit`.
