# lo-submit — сдать задачу на проверку

Если ты не ZCode (worker) — остановись, этот скил не для тебя.

Протокол: `docs/agents/coop-protocol.md`. Шаблон: `docs/agents/work/_templates/report.md`.

## Шаги
1. Ты на ветке `z/T-NNN-<slug>`, статус задачи `in_progress`.
2. Прогони `uv run pytest`, `python tools/check.py` и команды из «Проверок» задачи.
   Красные проверки — не сдаёшь: чини или переходи к `lo-blocked`.
3. Пройди критерии приёмки. Каждый должен подтверждаться тестом или командой.
4. Проверь diff (`git diff main...HEAD`): нет файлов вне «Можно трогать», нет отладочного мусора,
   нет секретов.
5. Допиши в `report.md` новый раунд `## Раунд N` (файл создай из шаблона, если его нет):
   - сделано, проверки с реальным сокращённым выводом, отклонения, замеченное «Вне задачи», вопросы;
   - со 2-го раунда — «Ответ на ревью»: каждая находка прошлого раунда `fixed <sha>` или
     `disputed: <довод>`. Молча пропущенная находка считается незакрытой.
6. Поставь `status: review` в `task.md`.
7. Закоммить отчёт и статус: `T-NNN: report round N`, трейлер `Agent: zcode`.
   В `main` не мержи и не коммить.
8. Скажи пользователю одной строкой: «T-NNN готова к проверке, раунд N».
